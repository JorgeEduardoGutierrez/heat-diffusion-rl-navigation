Robotic Navigation Results with Heat-Diffusion Reward Shaping

This page presents the results of robotic navigation experiments using Heat-Diffusion Reward Fields to accelerate learning with the Soft Actor-Critic (SAC) algorithm. The goal is to evaluate how shaped rewards based on heat-diffusion influence learning speed and success rates in environments with convex and concave obstacles.

Scenario Configurations

The experiments explore four types of initial conditions, varying the positions of the robot and the goal:

  • Fixed Start Configuration (FSC) – Fixed Goal Position (FGP): Both positions remain constant throughout training.
  • Fixed Start Configuration (FSC) – Random Goal Position (RGP): The robot starts from a fixed position; the goal changes each episode.
  • Random Start Contiguration (RSC) – Fixed Goal Position (FGP): The goal remains fixed; the robot starts from different positions.
  • Random Start Configuration (RSC) – Random Goal Position (RGP): Both the robot and goal positions change in every episode.

Experimental Variants

For each configuration, we evaluate the following five methods:

  • Sparse: Standard SAC algorithm with sparse terminal rewards only.
  • Heat Diffusion Only (HDRF): Dense rewards are computed by solving the heat equation from the goal position.
  • Heat Diffusion + Reward Filter (HDRF + RF): The agent only receives reward when moving toward higher diffusion values.
  • Heat Diffusion + Reward Decay (HDRF + RD): Intermediate rewards decay over time to encourage early success.
  • Heat Diffusion + Reward Filter + Reward Decay (HDRF + RF + RD): Combines both reward filtering and time decay on top of the diffusion field.

Training Metrics Reported

Below each set of experiment videos, we include a performance plot titled Training Performance Results. These plots display the success rate throughout training, measured both in training steps and in real-time minutes. Two key metrics are reported for each experiment:

  • Step and Time to 90% Success Rate: The earliest point during training at which the agent reaches at least 90% success rate.
  • Peak Performance: The maximum success rate achieved during training, along with the corresponding step and minute.
These indicators are used to assess convergence speed and final performance across all experimental methods.

Interactive Diffusion Maps

Below, we include two examples of the precomputed diffusion maps: one with convex obstacles and one with concave structures.
